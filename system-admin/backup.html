Restore a backup

Click Restore next to a saved backup. To restore a backup you downloaded earlier, use Upload a backup file first. When you restore, the system:

  1. asks for your password and for you to type RESTORE;
  2. makes a safety backup of the current data (it appears in the list above);
  3. replaces the database and the uploaded files with the ones in the backup;
  4. if anything goes wrong, puts the previous data back automatically;
  5. signs everyone out, including you. Everyone logs in again with the accounts in the backup.

Everything added or changed after the backup was made (accounts, grades, submissions, audit log entries) is replaced. To undo a restore, restore the safety backup. Try one restore before you rely on your backups.

Restore by hand instead (if the system will not start)

XAMPP is not required. The same steps are in RESTORE.txt inside each backup.

  1. Make a fresh backup of the current system first, if it still runs.
  2. Download the backup and unzip it (use 7-Zip or WinRAR if it has a password).
  3. Import database.sql into the Siknayan database with your server's database tool (for example phpMyAdmin, Adminer, HeidiSQL or your web host's Import page). See Import commands below for other ways.
  4. Copy files/private to backend/storage/app/private and files/public/profile-photos to backend/storage/app/public/profile-photos.
  5. Put your private copy of backend/.env in place, start the backend, and log in.

Importing into a database that already has data replaces it. Make a fresh backup first if you are not sure.

Import commands (hosted server, Docker, this computer)
  1. Hosted server or any computer with the MySQL/MariaDB client (use the DB_ values from backend/.env; it asks for the password):
    mysql -h DB_HOST -P DB_PORT -u DB_USERNAME -p DB_DATABASE < database.sql
  2. Docker (run in the project folder):
    docker compose exec -T mysql sh -c 'mysql -u"$MYSQL_USER" -p"$MYSQL_PASSWORD" "$MYSQL_DATABASE"' < database.sql
  3. This computer (Herd, Laragon, XAMPP or any local database): open your database tool, select the Siknayan database, choose Import and pick database.sql.
Make a backup by hand instead
  1. Export the Siknayan database as an SQL file, either with your database tool's Export page, or with:
    mysqldump -h DB_HOST -P DB_PORT -u DB_USERNAME -p --single-transaction DB_DATABASE > siknayan-2026-10-24.sql
  2. Name the file with the date, for example siknayan-2026-10-24.sql.
  3. Copy the folders backend/storage/app/private and backend/storage/app/public/profile-photos next to it.

The .sql file contains every account, including password hashes. Store it somewhere private.
